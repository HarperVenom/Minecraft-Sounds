Webpage to listen to any minecraft sound in real time.

Requirements:
- [node.js](https://nodejs.org/en)
- [npm](https://www.npmjs.com/)



1. Clone the repository:
  
   ```bash
   git clone https://github.com/HarperVenom/Minecraft-Sounds
   ```
2. Navigate to the project directory:
   ```bash
   cd Minecraft-Sounds
   ```
3. Run the server:
   ```bash
   npm start
   ```



It contains a script "getSoundsScript.js" for extracting minecraft sounds from /.minecraft folder on your pc. 
You can adjust the paths inside of the script (```getSoundsScript.js```) and extract all the files yourself by running:

```node getSoundsScript.js```

All the sounds extract into sounds folder.
